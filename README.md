## About the course

The course follows CRISP-DM from business question and corpus audit through preprocessing, feature engineering, text classification, sentiment evaluation, summarization and visualization. Learners work with fictional Singapore hotel reviews, not customer records.

## Learning outcomes

- Design a text analytics solution using CRISP-DM.
- Read and preprocess a text corpus with Python.
- Engineer text features and perform text analytics.
- Build and evaluate a sentiment model.
- Summarize and visualize findings with source evidence.

## Topics covered

1. CRISP-DM and corpus design
2. Text cleaning and vectorization
3. Text analytics and feature engineering
4. Sentiment modelling and evaluation
5. Summarization and visualization
